Sidetrack 0.4.1 follows the 0.4.0-rc1 test round and focuses on browsing, search and the keypad. Navidrome and Jellyfin, added in that release candidate, work as before. Playlists can now be created and edited. It updates in place, so nothing needs reinstalling.

## Library and search

- Compact rows are a new option in Appearance. They fit a fifth row on screen (82 dp rows, 64 dp artwork) and apply to every track, album, playlist and show row.
- Artist, album, playlist and show rows have their own actions, such as Follow, Artist radio, Save and Add to queue. Search results other than tracks now get the same actions as the library.
- Albums, artists, playlists and shows each remember the pages you loaded. Switching category no longer reloads from the top. A stale list refreshes in the background, without a spinner or cleared rows.
- Hold Left or Right to switch category in the library or scope in search. Search skips scopes that are switched off or that the service cannot answer. Each one restores the row and scroll position you left it at.
- Search keeps results per query and category, so switching scope no longer replaces all five lists from the top.

## Playlists

You can create a playlist, add tracks and remove them again. Actions appear only where the service allows them, and track counts update after an edit.

## Keypad

- The Welcome screen now teaches the keypad that is actually attached, and recognises T9 again. A game controller (Mini Controller) is identified from its D-pad.
- Pressing a key lights up the matching row in the accent colour.
- **Select keyboard** opens the Welcome screen and steps to the next keypad module, with or without Sidekit. If the app guessed wrong, you can correct it there.
- The Sundial now plays. Centre is play/pause, the Previous and Next edges are media keys, and the headset hook works. A held key repeats. This needs Sidekit 1.9.3.

## Menus

- Every Options bar and row action menu now comes from one shared definition, so the same entry no longer differs in label, icon or colour between screens.
- Colour follows what an entry does: accent for a live option, green for an option that is on, red for destructive actions, grey for Close, notices, Undo and Cancel. Destructive entries come last.
- On the queue, **Clear upcoming** moved into Options and the Shuffle toggle took its place. The queue row action **Delete** is now **Remove**.

## Playback and Home

- The sleep timer can end after the current track. Home and Now Playing show when the timer has paused playback. The countdown measures listening time, so pausing holds it.
- Recently played lists what you moved on from. The track playing now is not listed.
- Artwork no longer fails when a service sends an empty cover.

## Jellyfin

Creating a playlist now works. Sidetrack could not read the ID Jellyfin returned, so the form stayed open with "This track isn't available", and each retry created another playlist. Jellyfin now uses the official 12.x SDK, with a 30-second request timeout and a 6-second connection timeout.

## Upgrading

Package and signature are unchanged, so the app updates in place and keeps its history, queue, resume point and settings.

## Known issues

- Jellyfin 10.9 is refused, not supported. It signs in and then fails every read, so the check happens at sign-in.
- Neither Navidrome nor Jellyfin supports deleting items or writing a whole collection at once.
- Spotify library and search need the native bridge. Both APKs below include it. Without it, Spotify falls back to the public Web API, which rate-limits the desktop client ID.
